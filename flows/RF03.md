# Fluxos funcionais do RF03 — Gerenciamento de estoque

Este arquivo descreve o comportamento funcional das rotas de estoque independentemente da arquitetura utilizada. Os projetos podem distribuir as responsabilidades entre rotas, controllers, models, use cases ou repositories de maneiras diferentes, mas devem preservar a mesma ordem de validação, o mesmo fluxo de dados, as mesmas exceções e as mesmas respostas HTTP.

## Comportamento comum

Todas as rotas de estoque seguem inicialmente este fluxo:

1. Receber a requisição HTTP.
2. Validar o header `x-api-key` comparando-o com a variável de ambiente `X_API_KEY`.
3. Se o header estiver ausente ou tiver um valor diferente:
   - gerar `ForbiddenError`;
   - retornar HTTP `403` com `error`, `message` e `statusCode`.
4. Se a autenticação for válida, continuar o fluxo específico da rota.

A representação de produto retornada pelas rotas possui o seguinte formato:

```json
{
  "id": "0f5ead3a-8c1e-4b2a-9d4c-1a2b3c4d5e6f",
  "name": "Produto",
  "description": "",
  "price": 100,
  "stock": 25
}
```

## `GET /stocks`

Lista o estoque de todos os produtos.

### Fluxo

1. Consultar todos os produtos persistidos.
2. Ordenar os produtos pelo identificador para produzir uma resposta determinística.
3. Transformar cada produto para a representação HTTP contendo `id`, `name`, `description`, `price` e `stock`.
4. Retornar HTTP `200` com o array de produtos.
5. Se nenhum produto existir, retornar HTTP `200` com um array vazio.

### Validações e exceções

- A rota não recebe parâmetros de path, query ou body.
- Não existe exceção de produto não encontrado para uma listagem vazia.
- Além da autenticação comum, não há validação de entrada.

## `GET /stocks/{productId}`

Consulta o estoque de um produto.

### Fluxo

1. Obter `productId` a partir do path da requisição.
2. Consultar o produto persistido cujo identificador seja igual a `productId`.
3. Se o produto não existir:
   - gerar `ProductNotFoundError` com o identificador recebido;
   - retornar HTTP `404` com `error`, `message` e `statusCode`.
4. Se o produto existir, transformá-lo para a representação HTTP.
5. Retornar HTTP `200` com `id`, `name`, `price` e `stock`.

### Fluxo de dados

```text
productId do path
  → consulta do produto
  → produto encontrado
  → representação HTTP
  → resposta 200
```

### Exceção

```text
produto não encontrado
  → ProductNotFoundError
  → resposta 404
```

## `PUT /stocks/{productId}`

Define ou altera a quantidade absoluta em estoque de um produto.

### Entrada

O identificador do produto é recebido pelo path:

```text
productId
```

A nova quantidade é recebida pelo body:

```json
{
  "quantity": 25
}
```

### Fluxo

1. Obter `productId` a partir do path da requisição.
2. Obter `quantity` a partir do body.
3. Validar `quantity` antes de consultar o produto.
4. A quantidade é válida somente quando for um número inteiro maior ou igual a zero.
5. Se `quantity` estiver ausente, for não numérica, fracionária ou negativa:
   - gerar `InvalidQuantityError` com o valor recebido;
   - retornar HTTP `400` com `error`, `message` e `statusCode`;
   - não consultar nem alterar o produto.
6. Consultar o produto persistido cujo identificador seja igual a `productId`.
7. Se o produto não existir:
   - gerar `ProductNotFoundError` com o identificador recebido;
   - retornar HTTP `404` com `error`, `message` e `statusCode`.
8. Substituir o estoque atual pelo valor de `quantity`.
9. Persistir o produto atualizado.
10. Transformar o produto atualizado para a representação HTTP.
11. Retornar HTTP `200` com `id`, `name`, `price` e o novo valor de `stock`.

### Regra de atualização

`quantity` representa o novo valor absoluto do estoque. A operação não incrementa nem decrementa o valor atual.

```text
estoque atual = 10
quantity = 25
novo estoque = 25
```

O valor zero é válido e indica que o produto está sem estoque.

### Fluxo de sucesso

```text
productId do path + quantity do body
  → validação da quantity
  → consulta do produto
  → substituição do estoque
  → persistência
  → representação HTTP
  → resposta 200
```

### Fluxos de exceção

```text
quantity inválida
  → InvalidQuantityError
  → resposta 400
```

```text
quantity válida + produto não encontrado
  → ProductNotFoundError
  → resposta 404
```

## `PATCH /stocks/{productId}/increase`

Adiciona unidades ao estoque atual de um produto.

### Entrada

- `productId`: recebido pelo path.
- `quantity`: recebido pelo body.

```json
{
  "quantity": 5
}
```

### Fluxo

1. Obter `productId` a partir do path da requisição.
2. Obter `quantity` a partir do body.
3. Validar `quantity` antes de consultar o produto.
4. A quantidade é válida somente quando for um número inteiro maior que zero.
5. Se `quantity` estiver ausente, for não numérica, fracionária, igual a zero ou negativa:
   - gerar `InvalidQuantityError` com o valor recebido;
   - retornar HTTP `400` com `error`, `message` e `statusCode`;
   - não consultar nem alterar o produto.
6. Consultar o produto persistido cujo identificador seja igual a `productId`.
7. Se o produto não existir:
   - gerar `ProductNotFoundError` com o identificador recebido;
   - retornar HTTP `404` com `error`, `message` e `statusCode`.
8. Calcular `novoEstoque = estoqueAtual + quantity`.
9. Substituir o estoque atual pelo valor calculado.
10. Persistir o produto atualizado.
11. Transformar o produto atualizado para a representação HTTP.
12. Retornar HTTP `200` com `id`, `name`, `price` e o novo valor de `stock`.

### Fluxo de sucesso

```text
productId do path + quantity do body
  → validação da quantity
  → consulta do produto
  → soma ao estoque atual
  → persistência
  → representação HTTP
  → resposta 200
```

### Fluxos de exceção

```text

  → InvalidQuantityError
  → resposta 400
```

```text
quantity válida + produto não encontrado
  → ProductNotFoundError
  → resposta 404
```

## `PATCH /stocks/{productId}/decrease`

Remove unidades do estoque atual de um produto sem permitir estoque negativo.

### Entrada

- `productId`: recebido pelo path.
- `quantity`: recebido pelo body.

```json
{
  "quantity": 5
}
```

### Fluxo

1. Obter `productId` a partir do path da requisição.
2. Obter `quantity` a partir do body.
3. Validar `quantity` antes de consultar o produto.
4. A quantidade é válida somente quando for um número inteiro maior que zero.
5. Se `quantity` estiver ausente, for não numérica, fracionária, igual a zero ou negativa:
   - gerar `InvalidQuantityError` com o valor recebido;
   - retornar HTTP `400` com `error`, `message` e `statusCode`;
   - não consultar nem alterar o produto.
6. Consultar o produto persistido cujo identificador seja igual a `productId`.
7. Se o produto não existir:
   - gerar `ProductNotFoundError` com o identificador recebido;
   - retornar HTTP `404` com `error`, `message` e `statusCode`.
8. Comparar `quantity` com o estoque atual.
9. Se `quantity` for maior que o estoque atual:
   - gerar `InsufficientStockError`;
   - retornar HTTP `409` com `error`, `message` e `statusCode`;
   - não alterar nem persistir o produto.
10. Calcular `novoEstoque = estoqueAtual - quantity`.
11. Substituir o estoque atual pelo valor calculado.
12. Persistir o produto atualizado.
13. Transformar o produto atualizado para a representação HTTP.
14. Retornar HTTP `200` com `id`, `name`, `price` e o novo valor de `stock`.

Remover exatamente a quantidade disponível é permitido e resulta em estoque igual a zero.

### Fluxo de sucesso

```text
productId do path + quantity do body
  → validação da quantity
  → consulta do produto
  → validação do estoque disponível
  → subtração do estoque atual
  → persistência
  → representação HTTP
  → resposta 200
```

### Fluxos de exceção

```text
quantity inválida
  → InvalidQuantityError
  → resposta 400
```

```text
quantity válida + produto não encontrado
  → ProductNotFoundError
  → resposta 404
```

```text
quantity maior que o estoque atual
  → InsufficientStockError
  → resposta 409
```
